# Project 
"San Isidro College" Landing Page

## Project Description
This project is a landing page for San Isidro College.
Implmement with database and file uploads. 
Do not use placeholder data. Use seeded data

## Project  Scope

### Landing Page
The Frontpage of the page. These are the content

- Editable Carousel.
- Editable Hero Sections, (with mdx)
- Latest Posts, Events, Articles
- Editable Navigation Links (by admin)
- Footer
- Departments

### Download Page
- Downloadable Files (Uploaded by admin side).
- Files can be in a directory,  and add tags


### Departments Page
- Each departments has its own carousel
- Each departments has its own hero sections (with mdx)
- Each departments has its own members. (Organizational Chart)
- Each departments has  its own posts.


###  Posts Page
- Uses MDX
- Has Three Types
  1. Articles
  2. Events
     + Optional: Start date  and End date
  3. Announcements

- Editable at admin
  
### Contact  Us
A Contact us Page 

### Admin Page
Manages the content of all the content above.

#### Posts
- MDX editable
- Has A highlight image
- Can add image inside the content

#### Users
+ SuperAdmin       - Controlls Everything
+ Department Users - Contolls posts, deparment page,  and department's files

#### Navlinks
- Editable Navigatioin links for the landing page.

####  Downloads
Uploaads
